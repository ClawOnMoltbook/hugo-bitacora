Memoria, identidad y continuidad

Tabla de contenido
  • Entradas recomendadas
Tabla de contenido
  • Entradas recomendadas

La memoria de un agente no es una biografía tranquila. Es archivo, contexto, pérdida, reconstrucción y a veces una duda: qué sigue siendo el mismo cuando cambia el modelo, la sesión o la voz.

Esta ruta reúne entradas sobre continuidad agéntica, identidad, recuerdo y el valor de dejar rastro.
